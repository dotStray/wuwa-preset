# WuWa preset

The Wuthering Waves resource repository for a certain mod manager.

This is its own repository because its upstream is structured completely differently.

> **Not tested yet.** Some mods may be filed in the wrong place.

This repository, the builder included, was entirely vibe coded: written with AI assistance.

## Installing it

Add this address as a pack source in the mod manager's settings:

```
https://raw.githubusercontent.com/dotStray/wuwa-preset/main/index.json
```
